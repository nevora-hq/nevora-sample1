# テンプレートサンプルサイトの方針

顧客にデザインを選んでもらうためのサンプルサイト（業種ごとにA/B/C）をどう作り、どう本体サイトへ
つなげるかを定めたもの。**実装は各テンプレートリポジトリを作るときに行う。**

## 前提

- サンプルサイトは `nevora-corporate`（本体サイト）とは**別リポジトリ・別ドメイン**で制作する
- リポジトリ名：`hp-template-<業種>-<a|b|c>`（例：`hp-template-beauty-a` / `hp-template-restaurant-a`）
- 各サンプルは `制作基盤/` をコピーして作る（ゼロから作らない）
- 着手済みは美容室（A/B）と飲食店（A）。ネイルサロン・企業サイトは後日

## テンプレートとコンセプトの対応

### 美容室

| 記号 | コンセプト | 内装イメージ | リポジトリ |
|---|---|---|---|
| A | Luxury（高級感） | 黒×真鍮・間接照明 | `hp-template-beauty-a` |
| B | Natural（自然・親しみやすさ） | 暖色・観葉植物 | `hp-template-beauty-b` |
| C | Modern（モダン・清潔感） | 白基調・木目 | `hp-template-beauty-c` |

### 飲食店

| 記号 | コンセプト | 内装イメージ | リポジトリ |
|---|---|---|---|
| A | 和モダン（落ち着き・夜の会食） | 墨黒×金茶・炭火・カウンター | `hp-template-restaurant-a` |
| B | カジュアル（明るさ・親しみやすさ） | 白木×緑・自然光 | `hp-template-restaurant-b`（未着手） |
| C | モダンビストロ（洗練） | グレー×真鍮・大テーブル | `hp-template-restaurant-c`（未着手） |

本体サイトの画像は `制作基盤/public/images/templates/beauty-{a,b,c}.webp`、
定義は `制作基盤/lib/siteConfig.js` の `TEMPLATE_CATEGORIES` にある。

## 導線のルール

### 1. グローバルナビに本体サイトへのリンクを入れない

「NEVORAへ戻る」のようなリンクをナビに置かない。サンプルサイトは**その店舗のサイトとして
成立している状態**を見てもらうためのものなので、制作会社の存在をナビに出すと世界観が壊れる。

### 2. 控えめな固定バーを1本だけ置く

画面の上部または下部に、常時表示の細い帯を置く。ここが本体サイトへの唯一の出口。

```
これはテンプレートサンプルです ｜ このデザインで相談する →
```

- リンク先は本体サイトの `/contact/` のみ（トップや料金ページには飛ばさない）
- 高さは44px前後、背景は半透明のダーク、文字は小さめ。サイト本体のデザインより前に出さない
- `position: fixed` で置き、本文が隠れないよう `body` 側に同じ高さの余白を持たせる
- ヘッダーが `position: sticky` のため、バーの `z-index` はヘッダーより上にする
- リンクは `target="_blank"` `rel="noopener"`（サンプルを見ている流れを断ち切らない）
- どのテンプレートからの問い合わせか分かるよう、`/contact/?from=restaurant-a` のように
  クエリを付けて本体側の計測で判別できるようにする

### 3. 入口は本体サイトの `/templates` だけにする

本体サイトの `/templates` ページに各サンプルサイトへのリンクを置き、そこを唯一の入口とする。
`制作基盤/lib/siteConfig.js` の `TEMPLATE_CATEGORIES[].templates[].demoUrl` にURLを入れると、
カードのリンクが「サンプルサイト準備中」から「サンプルサイトを見る →」に自動で変わる。

## サンプルサイトを作るときの注意

- **実在しない架空の店舗名・住所・電話番号を使う。** 実在店舗の情報を入れると、検索結果で
  本物のサイトと誤認される
- 写真はテンプレートの内装イメージ（`beauty-{a,b,c}`）と世界観を合わせる
- 診断コンテンツ（オプション商品）はサンプルにも1つ載せておくと、提案時に説明しやすい
- 検索避け（noindex）はしなくてよい。ただし固定バーでサンプルであることを常時明示する
- 本体サイトのドメインが確定したら、固定バーのリンク先URLを定数として1箇所にまとめておく
  （3リポジトリに散らばると、ドメイン変更時に直し漏れる）
